# wplugins
Un sencillo script para la recoleccion de plugins de WordPress mediante una peticion GET y analizando el codigo fuente del WordPress.   ||   A simple script for collecting WordPress plugins using a GET request to analyzing the WordPress source code.

## Syntaxis

```bash
./wplugins.sh -u <URL> -p <PUERTO>
```
